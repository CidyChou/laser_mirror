# 明亮卡通版 · 横竖宣传图

使用内置 image_gen 制作，沿用文字主视觉分享图的天蓝背景、暖橙猫、黄白大字和局部光学道具。

三组宣传文案：
1. 转动镜子 / 点亮终点！
2. 光线会拐弯 / 脑筋也要转！
3. 200关挑战 / 等你来点亮！

竖版3张：720×1280 JPEG，每张小于200KB。
横版3张：1280×720 JPEG，每张小于200KB。

portrait和landscape文件夹是对应的压缩导出；originals保留高分辨率原始PNG。每种画幅重新排版，不将竖版直接裁切或拉伸为横版。

主视觉为文案和角色表情。底部镜面和短光路体现游戏玩法：右向光束在/镜面处转向上方；双镜图在第二个/镜面处继续转向右方。均为玩法概念插画，不是实机截图。没有完整棋盘、外部广告、玩家头像或个人信息。

完整生成提示词分别见prompts-portrait.md和prompts-landscape.md。
