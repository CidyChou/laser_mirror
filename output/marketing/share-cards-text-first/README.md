# 光线急转弯 · 文字主视觉分享图

本批使用内置 image_gen 重做构图，参照用户给出的数字圈圈乐图片：天蓝背景、暖橙角色、黄白大字。主视觉为文案，猫的表情作为互动陪衬，游戏元素仅在底部以少量镜面和短光路点缀。

保留三组文案：
- 通关挑战：就这？你也行？
- 好友邀请：不会吧！这都不敢来？
- 卡关邀请：差一个转弯！你来试试？

不展示完整关卡棋盘；底部光路为概念插画，不代表玩家当前关卡截图。可见反射按照左侧入射、/镜转向上方的有效方向设计。

每张提供1000×800与500×400 JPEG（5:4）；原始PNG保留在originals。导出目标小于200KB，便于上传；这是本批压缩目标，后台分享图大小限制未单独确认。

提示词保存在prompts.md。上传审核通过后，将imageUrlId与imageUrl一起传入转发方法，并保留现有关卡query参数。
