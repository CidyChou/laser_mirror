# 光线急转弯 · 柔和互动分享图

本批使用内置 image_gen 对上一批原图进行色彩和光影编辑，保留文字和棋盘光路。

背景改为灰蓝，亮黄改为暖金，纯白改为米白。镜面使用柔和青蓝，减少霓虹边缘、闪光、光斑及色彩饱和度，保留低强度粉红光束与浅2.5D质感。

每张提供1000×800及500×400 JPEG，比例5:4；另保留原始PNG。文件小于200KB是本批方便上传的导出目标，分享后台限额未单独核实。

01-taunt：通关好友挑战，「就这？你也行？」。
02-dare：普通好友邀请，「不会吧！这都不敢来？」。
03-help：卡关求助，「差一个转弯！你来试试？」。

求助图保留中央反斜杠镜、向下射出棋盘的光束及未点亮的上方终点。挑战图保留有效通关光路。完整编辑提示词见prompts.md。
