# 新手引导

第一关只保留「接通光路 → 点一下镜子 → 发射试试」3 步。以后第一次遇到某种机关时，用一张短卡介绍新增内容，读完即可游玩；每次进入最多显示 3 步，尚未展示的知识留到以后出现时介绍。可跳过，设置中的「重看本关引导」可随时重新学习。清理历史记录也会重置引导。

## 编辑棋盘

- 移动道具、调整行列、改变光源和终点、调整道具顺序，不需要修改引导。锚点从当前棋盘提取，再使用正式棋盘的几何计算定位。
- 传送门根据 `pair` 配对；开关和门根据 `id` / `requires` 关联；双束终点与聚合核心根据 `need` 生成数量说明。第一次遇到新的充能数量或多开关光门，也会提示。
- 开关与光门合并介绍，带锁的镜子、分光器和聚合核心共用一条说明；不再单独介绍墙体和多个普通终点。
- 只有带 `timeBoss` 的动态章节挑战增加换向次数与激光寿命提示。普通 `mode: "challenge"` 棋盘不再额外展示通用挑战说明；GM 编辑器仍保留挑战属性。
- 引导说明框自动选择位置与宽度，避开实际高亮目标和手指。设置、选关、结算和发射过程会暂停显示。
- 完全新增一种道具类型时，在 `src/gameplay/tutorial.ts` 的 `lessonsFor` 中增加识别和说明规则即可，不需要逐关编排。

## 操作教学与存档

`TutorialDirector` 管理步骤与操作条件，`TutorialLayer` 只负责展示；引导点击与普通点击共用应用的旋转和发射处理。首关操作教学通关后才完成，失败或发射中断可继续；旋转教学必须达到现场计算的朝向，不能通过「继续」跳过。

基础教学仅在没有新增机关、最多需调整一个道具的简单棋盘引导操作。它使用正式 `LaserSimulator` 查找可行操作，最多枚举 256 种状态，并限制搜索时间。已经接通的镜面不会要求再转；复杂或暂时无解的自定义棋盘自动回退为简短说明，可自由开始游玩。解法、关卡序号和手指坐标都没有写入教程配置。

学习记录独立保存在 `laser-mirror-tutorial-v1`。旧玩家首次升级时，根据已通关棋盘推断已经掌握的机制；未见过的机制仍会教学。旧版已学过任一种固定道具的玩家不会重复看到锁定说明。跳过只影响本次队列中的知识，不会把因 3 步上限而推迟的知识标记为已学。

手指使用提供的原图，复制到 `public/ui/tutorial/finger.png`，由现有跨平台资源加载器加载并打包。新机关说明优先高亮非诱饵道具，并关联传送门配对、光门开关等位置，不再追加解法操作教学；棋盘数据本身保持可由关卡编辑器继续调整。

## 验证

- `npm run verify:tutorial`：首关 3 步通关、每次最多 3 步、短文案、合并与推迟知识、200 关首次机制覆盖、移动棋盘、无解/复杂棋盘回退、配对和计数、存档迁移、跳过重看、GM 挑战标记往返、教学关可解性。
- `npm run typecheck`、`npm run validate:levels`、`npm run verify:optics`、`npm run verify:mechanisms`。
- `npm run dev` 后打开 `/tools/visual/tutorial.html?level=1&theme=void`。支持 `level=1…200` 及 `void` / `aurora` / `white` 三种主题，使用正式应用和内存存档，不修改玩家存档。章节挑战使用 `stage=boss:1…boss:20`；界面适配参数见 [界面美化说明](UI_POLISH.md)。

本次浏览器检查覆盖精简后的首关 3 步排版、实际旋转与发射通关。Web、微信、抖音和小红书产物均已构建；真机运行仍需在各平台开发者工具验证。
