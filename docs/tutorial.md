# 新手引导

第一关通过「光源 → 目标 → 镜面说明 → 实际旋转 → 发射通关」教学。以后第一次遇到某种机关时，只介绍新增内容；首次进入带 `mode: "challenge"` 标记的棋盘时，介绍挑战的观察方法。可跳过，设置中的「重看本关引导」可随时重新学习。清理历史记录也会重置引导。

## 编辑棋盘

- 移动道具、调整行列、改变光源和终点、调整道具顺序，不需要修改引导。锚点从当前棋盘提取，再使用正式棋盘的几何计算定位。
- 传送门根据 `pair` 配对；开关和门根据 `id` / `requires` 关联；双束终点与聚合核心根据 `need` 生成数量说明。第一次遇到新的充能数量或多开关光门，也会提示。
- 挑战属性随棋盘保存，不根据关卡序号判断。当前 101–130 关已标记，GM 编辑器中可勾选「挑战关卡」，导入和导出会保留此属性。
- 引导说明框自动选择位置与宽度，避开实际高亮目标和手指。设置、选关、结算和发射过程会暂停显示。
- 完全新增一种道具类型时，在 `src/gameplay/tutorial.ts` 的 `lessonsFor` 中增加识别和说明规则即可，不需要逐关编排。

## 操作教学与存档

`TutorialDirector` 管理步骤与操作条件，`TutorialLayer` 只负责展示；引导点击与普通点击共用应用的旋转和发射处理。基础教学通关后才完成，失败或发射中断可继续；旋转教学必须达到现场计算的朝向，不能通过「继续」跳过。

简单棋盘使用正式 `LaserSimulator` 查找可行操作，最多枚举 256 种状态，并限制搜索时间。已经接通的镜面不会要求再转；复杂或暂时无解的自定义棋盘自动回退为说明式教学，可自由开始游玩。解法、关卡序号和手指坐标都没有写入教程配置。

学习记录独立保存在 `laser-mirror-tutorial-v1`。旧玩家首次升级时，根据已通关棋盘推断已经掌握的机制；未见过的机制仍会教学。跳过只影响本次队列中的知识，不影响以后出现的新道具。

手指使用提供的原图，复制到 `public/ui/tutorial/finger.png`，由现有跨平台资源加载器加载并打包。首次出现分光镜、机关、传送、聚能和聚合时，教程会按现场解法优先高亮有效道具；棋盘数据本身保持可由关卡编辑器继续调整。

## 验证

- `npm run verify:tutorial`：首关通关、130 关首次机制覆盖、移动棋盘、无解/复杂棋盘回退、配对和计数、存档迁移、跳过重看、GM 挑战标记往返、教学关可解性。
- `npm run typecheck`、`npm run validate:levels`、`npm run verify:optics`、`npm run verify:mechanisms`。
- `npm run dev` 后打开 `/tools/visual/tutorial.html?level=1&theme=void`。支持 `level=1…130` 及三种主题，使用正式应用和内存存档，不修改玩家存档。

浏览器检查覆盖实际点击通关、提前发射拦截、跳过与重看、设置暂停、切换主题、补充爱心、发射中断和清理记录。对 130 关完整重看时生成的 1,241 个步骤，检查说明排版与高亮区域；另检查手机小屏和窄高屏。小游戏产物已构建，真机运行仍需在各平台开发者工具验证。
