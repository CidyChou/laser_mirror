# 金币与爱心

目标是让前期简单关卡积累有限储备，中后期失误消耗储备。金币能正常买到爱心，广告作为补给选择；熟练玩家保留通关所得，不通过强制扣币或提高售价清空余额。

## 固定数值

| 普通关首次通关 | 金币 |
| --- | ---: |
| 1～10 | 6 |
| 11～30 | 8 |
| 31～80 | 10 |
| 81～140 | 12 |
| 141～200 | 14 |

章节挑战按对应关卡档位发放两倍，最高 28 金币。可自愿观看通关翻倍视频再领一份本次奖励。重玩不重复发币，不再提供重玩的翻倍入口。

| 资源 / 入口 | 数值 |
| --- | --- |
| 新玩家起始储备 | 一次 40 金币，初始 5 心 |
| 买 1 心 | 20 金币 |
| 从 0 补满 5 心 | 80 金币 |
| 缺 1～4 心时补满 | 按实际缺少数量 × 20，不出售溢出的爱心 |
| 不够补满时 | 可按余额一次购买 2～3 颗，或只买 1 颗 |
| 心视频 | 补满至 5 心 |
| 自然恢复 | 每 10 分钟 1 心，最多 5 心；离线有效 |
| 金币视频 | 每次 60，每天最多 3 次；余额达到 200 时暂停额外金币视频 |
| 金币提示 | 60 金币调整一处物件；保留视频提示和免费玩法说明 |

金币视频仍与提示、通关翻倍共用原有每日 8 次额外领奖额度。心视频独立处理。取消、失败、缺少明确观看完成状态、切关和重复回调不发额外奖励，也不扣领奖次数。广告 ID 留空时没有模拟领奖，仍可用金币买心或等待自然恢复。

40 金币起始储备可直接买 2 心；后续正常首通约 2～4 关可买 1 心。前 30 个普通关及对应章节挑战共发 264，加起始储备为 304：考虑到前期消耗较少，足以留下一些应对后续难关的储备。没有增加随关卡编号上涨的爱心价格。

全主线 200 普通关及 20 个章节挑战首次通关总产出为 **2,736** 金币。原有线性公式是 **51,880**，并且可以重玩领取；新公式有上限，也封住了反复刷简单关的产出。通关翻倍仍与实际完成的首通奖励一一对应，不会无限重领。

金币广告是低余额补给，不强行限制正常赚取的余额。余额 199 时完整看完仍获得 60，到 259 后暂停金币视频；保留全部承诺奖励。旧存档的合法金币余额保留，升级不削减或强制换算。新玩家起始储备只初始化一次，重新打开不再领取；清理玩法历史仍会清空金币，不重复赠送。

## 界面

选关页右上角是金币余额与「＋」。点击「＋」直接进入金币视频，点击余额打开补给；游戏内点击爱心或补给入口可购买爱心。选关页不展示攻略交流按钮，进度信息居中。

爱心不足时先展示实际缺少数量、金币价格和视频选项。已满、余额不足和过期的购买报价不会扣币；成功购买保留当前镜面，停留在选关页购买时也保留选关页。恢复计时从掉出满心时开始，未满时购买或获得部分爱心不会重新拖延正在进行的恢复计时，满心后停止累计。后台、重启和一场试射结束时都会核对自然恢复。

## 规划模拟

`npm run verify:economy` 使用当前实际关卡顺序，按早期到后期递增的失误率模拟三种玩家。计入章节首次失败保护、自然恢复、金币购买和可选的金币提示；需要补给且金币不足时使用心视频。模拟的普通关耗时为前 30 关每关 25 秒、31～80 每关 45 秒、以后每关 70 秒，每次失败额外 15 秒。

这些是用于检查资源是否断裂的规划假设，尚无真实玩家统计，不能用于承诺真实广告观看率或收入。

| 模拟玩家 | 首通产出 | 扣心失败 | 金币购买心次数 | 心视频 | 前 30 关心视频 | 金币提示 | 最后余额 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 熟练 | 2,736 | 103 | 19 | 0 | 0 | 0 | 1,256 |
| 普通 | 2,736 | 247 | 60 | 23 | 0 | 6 | 56 |
| 反复尝试 | 2,736 | 386 | 90 | 49 | 0 | 1 | 36 |

规划里三种玩家的前 30 关都不依赖心视频；熟练玩家可以靠正常产出完成全程，较多失误才逐渐消耗储备并使用额外补给。上线后应根据实际的失败次数、金币余额分布、补心次数及看完后继续游戏的情况调整，优先维持新手前期的体验。

## 配置与检查

`src/economy/config.ts` 集中配置首通档位、起始储备、心价格和恢复间隔；`templates/wechat/operations.json` 的 `rewards` 配置视频金币、每日上限和储备门槛。重新构建后生效。

回归验证包括新档 / 旧档、首通 / 重玩、补心不足 / 已满 / 多颗购买、重复报价、不丢镜面布局、自然恢复边界 / 离线 / 满心停止累计、金币视频取消 / 完成 / 日限 / 储备门槛与余额更新。真实广告仍需填入本游戏 ID 后真机验收。

本次通过浏览器实际画布点击验证金币「＋」、视频取消 / 完成、20 金币购买 1 心、80 金币补满、从选关页购买后保留选关页，以及广告配置留空时的金币购买。真实关卡解题验证首通增加 6 金币、重玩增加 0；模拟离线 20 分钟恢复 2 心。选关、爱心和提示界面已检查 390×844、360×640、375×812 三种尺寸。模拟 SDK 不代表真实广告已开通或产生收入。
