# 首发手感调整 · 2026-10-14

将蓄力、出膛、反射、通关、入账连成连续反馈，改善发射器贴边和等待过长的问题。

| 项目 | 调整 |
| --- | --- |
| 发射器间距 | 枪口距棋盘从 9 增至 24–29.1 个设计像素，至少比外框多留 14 像素；布局同时预留完整机身，四个方向均不会裁切。接收器保留原来的贴边间距；光束终点、命中特效和教学高亮跟随各自位置。 |
| Combo 音效 | 保持原有六档层次，播放音量统一乘 0.94。 |
| 长按蓄力 | 1200 → 1050 ms；末段能量核心增强，完成后立即出膛；取消或完成时停止蓄力音。音频预热不再截断首次蓄力。 |
| 发射冲击 | 定向枪口闪光、更多高速火花、110 ms 的轻量棋盘闪光、220 ms 的回弹；棋盘位移最多 8 个设计像素，HUD 保持稳定。 |
| 震动 | 出膛采用强 / 中两次短脉冲，间隔 100 ms；发射与获胜可越过低优先级限频。命中镜面使用中档反馈；关闭震动、切后台和销毁时取消待发脉冲。 |
| 普通光路节奏 | 同一时刻的推进距离乘 1.32；反射停顿距离 34 → 20。章节挑战保留 0.8 倍速度及 34 的停顿距离。机关的充能、传送与开门时长保留。 |
| 命中反馈 | 镜面瞬时弹动 / 回位、沿入射方向位移、更亮的白热闪光和喷溅；多束同时命中的整体位移有上限。 |
| 粒子时钟 | 由逐帧减寿改为按时间推进，30 / 60 / 120 FPS 下保持相同轨迹和消退。 |
| 结算衔接 | 连击收尾 720 → 420 ms，胜利后结算等待 900 → 480 ms；按钮在面板进入 220 ms 后开始出现。 |
| 彩带与金币 | 彩带高 / 中 / 低画质分别为 110 / 76 / 44，长纸带与纸屑在 90 ms 内一次喷出，随后自然下落；飞金币上限分别为 24 / 18 / 12，扩散范围增大并保持在屏幕内。金币在结算面板出现 900 ms 后再喷出，确保彩带已转为下落。实际奖励金额保持原规则。 |

## 验证

- `npm run typecheck`、`verify:feedback`、`verify:render-layout`、`verify:optics`、`verify:portals`、`verify:time`、`verify:tutorial` 通过。
- 96 组棋盘 / 端口组合、200 个主线解法和 20 个动态章节挑战通过；章节挑战包含 30 / 60 / 120 FPS 及操作时间浮动验证。
- 浏览器实操验证提前松手、完整长按、自动出膛、逐次镜面命中、获胜、金币完整入账及空闲停帧。
- 320 / 390 / 430 像素宽度、两种主题、平台顶部安全区及大小棋盘均无端口机身裁切。
- WebGL1 / Graphics 低画质实操通关通过：12 枚飞金币、44 片彩带；高画质实操通关通过：24 枚飞金币、110 片彩带。
- 27 组金币结算场景通过：不同画质、奖励额和中途离开时机均没有丢失或重复入账。
- 二轮细调实操：第 3 关的金币在获胜约 1.39 秒后开始出现，此时 110 片彩带均已下落；金币开始前直接点击下一关，奖励正常入账，旧动画无残留。
- 粒子 30 / 60 / 120 FPS 的坐标、透明度和缩放差异小于 `3e-14`，均正常消退；已有渲染创建 / 销毁 / 重建回归通过。
- Web 与微信构建通过；微信包约 2.79 MB。手机马达的实际震动强弱仍需真机感受确认。
