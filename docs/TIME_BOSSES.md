# 章节挑战

每章第 10 关后追加一个独立动态挑战，共 20 关，顺序为“第 10 关 → 第 1 章挑战 → 第 11 关”。主线共 200 关；旧主线、新主线与挑战分别以稳定的 `level:N`、`flow:N`、`boss:N` 保存，显示编号独立于存档身份。最新编排见 [200 关扩充记录](campaign-200.md)。

## 操作与寿命

- 神之手：发射后直接点击非固定镜、分光器或聚合点，每次成功旋转消耗一次；蓄力中不能操作，空格与固定部件不扣次数。
- 时光回溯已经移除。子弹时间继续保留底层能力，正式 20 关配置为零，客户端不展示。
- 挑战速度保持普通光束加速曲线的 80%。光束初始最多有六格尾迹，发射后随寿命连续缩短，界面显示寿命条和秒数。
- 神之手次数用完后最多再保留 6 秒，让在途光束完成目标；自然寿命更早耗尽则按较早时间结束。无法再传播的光束在 0.9 秒内消散。
- 光束寿命归零时未完成目标，试射失败；归零之前完成则立即胜利。发射前 480ms 蓄力、后台暂停和技能教学暂停不消耗寿命。
- 每次重新发射恢复配置次数与完整寿命。每个章节挑战保留一次免费失败保护，此后失败扣一颗心，心耗尽显示失败面板。“结束本次试射”仍可提前结算失败。

## 实现与维护

`TimeLaserSimulator`按实际碰撞读取部件方向并生成分支；已经走过的光路不会重新解释。聚合器按不同入射方向充能，蓄力 1.5 秒后输出三倍宽光束。普通关仍由 `LaserSimulator` 求解。

`GameSession`以 10ms 前台时间步推进寿命，逻辑状态的 `beamLife` 同时控制 GPU 与 Graphics 尾迹长度及失败判定。模拟器只保留最近六格光段，不再复制历史世界快照。

正式关卡读 `src/levels/time-bosses.json`；`scripts/time-boss-designs.ts` 包含布局和由实际碰撞时间生成的开发回放。GM 可配置神之手次数与激光寿命（8–60 秒）。

校验页 `/tools/visual/time-bosses.html` 支持 20 关、三种主题、GPU/Graphics 与手动操作；`pose=won|spent|fading|failed` 分别定格通关、次数耗尽后、消散末期与失败。页面不读写玩家存档。

```sh
npm run verify:time
npm run analyze:levels
npm run validate:levels
npm run verify:optics
npm run verify:mechanisms
npm run verify:tutorial
npm run verify:render-layout
npm run typecheck
npm run build:all
```

验证包含全部静态配置无解、规定次数内动态通关、30/60/120 FPS 与 ±50ms 操作偏移一致、遗漏换向失败、聚合点不可绕过、有限寿命、重试和存档迁移。`analyze:levels`另行验证每 10 关出现难度高点，以及至少 100 个主线关卡包含聚合点。
